Création d'une base de données

SQL

Contexte

Lors de ce projet, nous avons conçu et rempli une base de données en 3 étapes distinctes pour l'association « Le Tourmentin », qui organise des activités maritimes : sorties en mer et rallyes de voiliers.

Réalisation

  • Étape 1 — Schéma MCD sur papier puis dérivation du MLD, avec justification des contraintes nécessitant des triggers.
  • Étape 2 — Création du fichier CREATE depuis le MLD, du fichier DROP et d'un fichier de test pour vérifier les contraintes.
  • Étape 3 — Mise à jour et interrogation de la base à partir d'un jeu de données fourni.

Technologies utilisées

  • SQL
  • Modélisation MCD / MLD
  • Triggers

Compétences acquises

  • Conception et modélisation d'une base de données
  • Écriture de requêtes SQL complexes
  • Mise en place de contraintes et triggers
