Installation Debian 13

LINUX

Contexte

Lors de ce projet, j'ai installé une interface Linux via une machine virtuelle sous Debian 13. En suivant une procédure en plusieurs étapes, j'ai configuré l'environnement de développement depuis zéro, en vérifiant l'espace disque, la langue, les packages et les outils nécessaires.

Compétence visée

  • Installation d'un poste pour le développement

Technologies utilisées

  • Linux / Debian 13
  • SSH
  • IntelliJ IDEA
  • Flatpak et Snap

Réalisation

  • Création de l'empreinte SSH et configuration de la machine virtuelle
  • Paramétrage de la langue, localisation et interface graphique
  • Installation des packages Java et des outils nécessaires en mode administrateur
  • Installation d'IntelliJ IDEA en flatpak et snap pour comparer l'espace disque utilisé

Compétences acquises

  • Fonctionnement et installation de Debian
  • Gestion de packages Linux en ligne de commande

Savoir-faire acquis

Capacité à installer et configurer un environnement de développement Linux depuis zéro, en choisissant les outils adaptés et en les gérant via le terminal.
