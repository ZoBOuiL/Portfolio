Projet Chatbot

JAVA

Contexte

Nous avons créé un chatbot dont le but était de répondre à de simples questions via le terminal. L'utilisateur pouvait poser des questions prédéfinies ou en apprendre de nouvelles au bot. Nous avons également ajouté la fonctionnalité de garder en mémoire les échanges afin que le bot puisse répondre à l'aide d'un contexte.

Compétences visées

  • Réaliser un développement d'application
  • Optimiser des applications informatiques

Technologies utilisées

  • Java
  • Structures de données indexées
  • Algorithmes de recherche

Réalisation

J'ai principalement travaillé sur la recherche par index : les fonctions permettant au bot de trouver intelligemment les réponses parmi les questions enregistrées. Nous avons ensuite rédigé un rapport avec des calculs algorithmiques pour mesurer l'efficacité de ce système comparé à une lecture ligne par ligne.

Compétences acquises

  • Complexité algorithmique
  • Organisation d'un projet en Java

Savoir-faire acquis

Expérimentation concrète d'un projet Java, de la conception à l'analyse des performances.
