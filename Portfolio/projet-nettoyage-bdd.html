Nettoyage d'une base de données

SQL

Contexte

En binôme, nous avons travaillé sur la base de données OpenFoodFacts, centrée sur le nutri-score. Étant open source, n'importe qui pouvait y entrer des données, ce qui rendait la base très hétérogène. L'objectif était d'extraire les informations correctes pour analyser les produits céréaliers en France : sélection des lignes valides, filtrage par pays et catégorie, puis création de graphiques pour visualiser les résultats (ex. proportion de produits bio parmi les céréales).

Compétence visée

  • Gérer des données de l'information

Technologies utilisées

  • SQL
  • OpenFoodFacts (base open source)

Réalisation

  • Écriture du script SQL de nettoyage pour supprimer les lignes incorrectes ou incomplètes
  • Filtrage des produits céréaliers français avec les mentions spécifiques requises
  • Création de graphiques exploitant les données nettoyées (ex. part de produits bio)

Ma contribution

  • Script de filtrage et nettoyage des données
  • Sélection des critères de qualité des lignes

Compétences acquises

  • Nettoyage et fiabilisation d'une base réelle
  • Analyse et visualisation de données SQL
